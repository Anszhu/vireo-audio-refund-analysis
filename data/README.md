# Data

Client data is confidential and **not committed**. Place these files in `data/raw/` before running:

`tickets.csv` · `agents.csv` · `orders.csv` · `customers.csv` · `products.csv` (and optionally `support-policy.pdf`).

`data/processed/` is generated by `python -m src.pipeline` and is git-ignored. `raw_checksums.txt` holds SHA-256 hashes of the analysed files.
